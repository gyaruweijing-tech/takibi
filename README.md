# takibi

ただ焚き火を焚くだけの3Dブラウザアプリ。いちばんのこだわりは「写真のようなリアルさ」。

- 炎：実写の炎の映像から作ったパラパラ漫画（フリップブック）を、燃えている場所ごとに置く
- 薪・地面・石：実物をスキャンした素材（Poly Haven、CC0）
- 燃え方：薪を小さなマス目に分け、熱の伝わり・熱分解・炭化をマスごとに計算する
- はぜ：薪の中に散らばった水分のたまりが熱で破裂する。火の粉・音（プログラム合成）・振動（ゲームパッド）が同時に出る

## 起動
```
npx -y http-server . -p 5191 -c-1
```
http://localhost:5191 を PC の Chrome で開く。

## 遊び方
- 下の棚で材料を選ぶとカーソルについてくる。**石の囲いの上でクリックして置く**（止まる所は薄い影で出る。ホイールで持ち上げると上から落とせる。Shift＋ホイールで向き、右クリックでやめる）
- **マッチ**：選んでクリックで擦って置く。**火ばさみ**：薪をクリック → 動かす先をクリック
- 左上の ≡ でモードを選び直す
- **スペース長押し**で息を吹きかける（V でマイク）、M で音を消す
- `?debug` で温度・はぜの回数・fps、f キーで燃焼だけ10倍速。`?bench` で部品ごとの重さ（GPU の時間）

## 道具
- `node tools/sim.mjs [match|start|single|hour]` … 燃焼だけを画面なしで回して秒数を測る
- `node tools/footage-flames.mjs <動画> <名前> x,y,w,h` … 焚き火の動画から炎のパラパラ漫画を作る（ffmpeg が要る）
- `node tools/bake-smoke.mjs` … 6方向ライトの煙を焼く
- `node tools/fetch-polyhaven.mjs` … Poly Haven の素材を落とす
