## 場面

- 地面を10cm掘ったくぼみに埋めた**石囲炉**（内側は直径76cmの円）。左に平たい岩（材料置き場）とたいまつ、後ろに横長の岩、奥に木
- **時間帯は本人の時計に合わせる**（開いた時刻の空になる）。いまは夜だけ → 作り直す
- 炉の石はグレー（0x7e7c79）。材料を置く平たい岩は暗いまま

## 大きさの決まり（自然観）

- **すべて実物大。** 大きさは「その世界にある物との比率」で決まる。薪より明らかに大きい火ばさみのような、比率のおかしい物を作らない
- 物ごとに倍率を変えない。見えにくいときは、物を大きくするのではなく**カメラ側で解決する**
- いまの実物の寸法（基準表）：

| 物 | 寸法 |
|---|---|
| 炉の内側 | 直径 76cm |
| 割り薪（針葉樹・広葉樹） | 長さ 32cm・幅 7.5〜8cm |
| 湿った薪 | 長さ 31cm |
| 小枝の束 | 長さ 30cm |
| 新聞紙（丸めたもの） | 約 11cm |
| マッチ | 軸 約 4.5cm（白木の軸） |

- いまとの差：手に持った道具は2.5倍、置いたマッチは1.6倍にしている（`js/tools3d.js` の HELD・LYING）→ 作り直す

## 操作

| 操作 | PC | スマホ |
|---|---|---|

| 吹く | スペース長押し／V でマイク | 未定 |

## 燃え方の時間

- **本物の約2倍長持ち。** いまの実測（`tools/sim.mjs`）：針葉樹の炎 約8分半、熾火は灰をかぶって最大3時間
- 燃え移りの目安：燃えている薪の上に置いた針葉樹は約1分で着火（2026-10-08 決定）
- 2倍にしたあとも、燃え移りの速さは保つ
