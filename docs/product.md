# product — 何を作るか

最終更新: 2026-10-08

ただ焚き火を焚き続けるだけの3Dブラウザアプリ。

## ゴールと評価基準（★いちばん上。作業ごとの完成条件はここから引く）

このアプリの気持ちよさは**瞬間ではなく継続にある**。シンプルな作業で、落ち着く火をずっと続けていく一連の流れそのものを体験させる。

| # | ゴール | 評価基準（どう確かめるか） | 確かめ方の種類 |
|---|---|---|---|
| G1 | **写真と見分けがつかない** | 「正解集」（炎の動画の元から切り出した静止画＋使ってよいネットの写真）と、同じ角度・同じ燃え方の段階のスクショを並べて、本人が見分けられない。判定は毎回同じ条件でする：同じ角度・同じ燃え方の段階（着火直後／炎が最大／熾火）・左右に並べた1枚の画像。その日の作業の直後には判定しない | 参考画像 → 本人 |
| G2 | **火の世話が気持ちいい** | 置く・落とす・燃えている薪を動かす・吹く、を続けて、本人が触ってOKを出す。下の「落ち着きを壊すもの」が1つも起きない | 本人が触ってOK |
| G3 | **ずっと眺めていられる** | 燃え方は**本物の約2倍長持ち**。基準は 2026-10-08 時点の実測（針葉樹の炎 約8分半）→ 目標 約17分。`node tools/sim.mjs`（燃焼だけ）と、ゲームの中の実測の両方で測る | 数値 |
| G4 | **軽く動く** | 本人の PC（Intel Iris Xe・1280×760）で 60fps。**本人のスマホでも 60fps**（2026-10-08） | 数値（`?bench`） |

## 落ち着きを壊すもの（やってはいけない）

1. **画面がピコンと変わる**：表示が急に出る・消える・ワープする（予告の影がワープして「気持ち悪い」と言われた前例がある）
2. **操作が思いどおりにいかない**：つかめない・視点が勝手に回る・置いた物が滑り落ちる
3. **重くてカクつく**
4. **文字やボタンが多い**：いま（下の棚と ≡ メニュー）より増やさない

## 誰のため

- 自分が眺めて落ち着く
- 公開して、知らない人に遊んでほしい
- 「ブラウザでここまでできる」を見せる作品

## 機能一覧

| 機能 | いま |
|---|---|
| 火おこし（マッチ → 新聞紙 → 小枝 → 薪） | ある |
| 薪3種（針葉樹・広葉樹・湿った薪） | ある |
| 置く・上から落とす（縦の板の持ち方） | ある |
| 燃えている薪も材料と同じ持ち方でつかむ（火ばさみはなくす） | **作り直す**（いまは火ばさみ） |
| 息を吹きかける（スペース・マイク） | ある |
| 灰を掃く | **ない**（2026-10-08 足すと決定） |
| はぜ（音・火の粉・振動） | ある |
| 熾火・灰・再開したら離れていた時間ぶん進める | ある |
| 視点：自由に見回せる＋固定ボタン | **固定ボタンがない** |
| 場面の時間帯を本人の時計に合わせる | **ない**（いまは夜だけ） |
| スマホ対応 | **ない**（すぐ対応したい） |

## やらないこと

- 点数・クリアなどのゲーム要素
- 他人とつながる機能（遠くに他人の焚き火が見える、など）
- 4D Gaussian Splatting・UE5・WebGPU（理由は PROGRESS の「やらないこと」）
